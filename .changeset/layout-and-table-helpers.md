Add `Breadcrumbs`, `PageSkeleton`, `RowActions` and `TruncatedText`. `Breadcrumbs` takes an injectable `LinkComponent` and marks the current page with `aria-current`; `PageSkeleton` draws a `list`, `profile` or `document` page layout behind a single "Loading" status; `RowActions` keeps a table row's action buttons on one line; `TruncatedText` ellipsises one line of text and shows the full value in a tooltip only when it is cut off.
