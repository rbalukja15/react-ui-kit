Add `StatusChip` and `DatePresets`. `StatusChip` shows a status and opens a menu of the statuses it may move to next, with per-status labels and colors and optional extra actions; without `onChange` it is a plain chip. `DatePresets` renders quick-pick chips like "+1 month / +3 months / +1 year" that add an interval to a base date (or today) and return an ISO `YYYY-MM-DD` string, with no date library needed.
